# COMP150_F26_Project1
Template code for COMP150_F26_Project1

## Team
Stephen Sarfo, Jessica Calderon, Stephen Gutierrez



## Files
`project1.py` - the file you need to edit as a team. You'll need to write code for the `encode()` and `decode()` functions. You are also expected to write helper functions to help you solve ciphered messages. 
`test.py` - a file that runs some quick tests on your project1.py functions. Might be helpful if you're not sure what is going wrong.

## How to run
You can run your python file via the command line (on your terminal)

`python3 project1.py encode "TEST MESSAGE"` will run the encode function

`python3 project1.py decode "TEST MESSAGE" "{test_dict: 'value'}"` will run the decode function
